# Portfolio — Mathéo THEFANY (BTS SIO SLAM)

## Structure

```
portfolio/
├── index.html            ← Entreprise : alternance actuelle + frise des expériences (page d'entrée)
├── competences.html
├── missions-e5.html      ← réalisations + tableau de synthèse E5
├── e6.html
├── certifications.html
├── veille.html
├── contact.html
└── assets/
    ├── css/
    │   ├── background.css  ← fond étoilé (fichier d'origine de MonPortfolio)
    │   ├── style.css       ← couleurs, polices, boutons, tags (commun)
    │   └── portfolio.css   ← menu du haut + mise en page des pages
    ├── js/
    │   ├── background.js   ← étoiles (fichier d'origine, étoiles filantes désactivées)
    │   ├── header.js       ← le menu du haut, écrit une seule fois pour toutes les pages
    │   └── missions.js     ← filtres, pastilles de compétences, tableau de synthèse
    ├── img/
    └── docs/               ← PDF : CV, tableau de synthèse officiel, documentations
```
